# Customer Shopping Feedback & EDA 📊🛒

This project is designed to collect, explore, and analyze customer ratings and feedback for purchased products to uncover hidden trends, satisfaction metrics, and behavioral patterns.

---

## 📁 Repository Structure

```text
customer_shopping_feedback/
│
├── Customer_Shopping_Feedback.ipynb     # Main Jupyter Notebook containing EDA and analysis
├── Data_Science.xlsx                    # Sample dataset containing customer shopping & feedback records
└── README.md                            # Project documentation
```

---

## 📌 Project Overview

This repository focuses on handling customer rating and feedback datasets. By applying Exploratory Data Analysis (EDA) techniques, we aim to understand what drives customer satisfaction, evaluate rating distributions, and derive actionable insights from customer purchase data.

### Key EDA Objectives & Highlights:
* **Data Cleaning & Preprocessing**: Handling missing values, checking data types, and structuring data for analysis.
* **Univariate Analysis**: Examining the distribution of individual features such as customer ratings, purchase amounts, and product categories.
* **Bivariate & Multivariate Analysis**: Exploring correlations between customer demographics, product ratings, and feedback sentiments.
* **Statistical Summaries & Visualizations**: Using charts and graphs to highlight key performance indicators (KPIs) and customer preference trends.

## 🛠️ Tech Stack & Requirements

To run this analysis locally, ensure you have Python installed along with the required libraries:

* **Language**: Python 3.8+
* **Data Manipulation**: `pandas`, `openpyxl`, `numpy`
* **Data Visualization**: `matplotlib`, `seaborn`
* **Environment**: Jupyter Notebook / Jupyter Lab

You can install the dependencies using pip:

```bash
pip install pandas openpyxl numpy matplotlib seaborn
```

## 🚀 Getting Started

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/sathishchandrasekar/customer_shopping_feedback.git
   cd customer_shopping_feedback
   ```

2. **Open Jupyter Notebook**:
   ```bash
   jupyter notebook Customer_Shopping_Feedback.ipynb
   ```

3. **Run the Analysis**:
   Execute the notebook cells sequentially to load `Data_Science.xlsx`, perform the EDA steps, and generate insightful visualizations.
